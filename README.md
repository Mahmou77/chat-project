## ⚡ خطوات التشغيل

### 1. تثبيت Node.js
→ https://nodejs.org (النسخة LTS)

### 2. إنشاء المجلد وترتيب الملفات
```
أنشئ مجلداً باسم: arabic-chat-pro
├── ضع server.js, db.js, socket.js, package.json, .env.example في الجذر
├── أنشئ مجلد middleware/ وضع فيه security.js
├── أنشئ مجلد routes/ وضع فيه الملفات الست
├── أنشئ مجلد public/ وضع فيه index.html, admin.html, admin2.js, setup.html
└── أنشئ مجلد public/games/ وضع فيه الألعاب الأربعة
```

### 3. إنشاء ملف .env
```bash
cp .env.example .env
# عدّل JWT_SECRET لكلمة سر عشوائية طويلة
```

### 4. تثبيت المكتبات
```bash
cd arabic-chat-pro
npm install
```

### 5. تشغيل السيرفر
```bash
npm start
# أو للتطوير:
npm run dev
```

### 6. أول تشغيل - الإعداد
```
افتح: http://localhost:3000/setup
```
ستظهر صفحة إعداد جميلة بـ5 خطوات:
1. مرحبا + عرض الميزات
2. اسم الموقع والوصف
3. حساب الأدمن (أول مستخدم = صاحب الموقع ID#1)
4. اختيار الثيم والألوان والخط
5. تم! ادخل الشات أو الأدمن

### 7. الروابط بعد الإعداد
```
الشات:   http://localhost:3000
الأدمن:  http://localhost:3000/admin
الإعداد: http://localhost:3000/setup (مرة واحدة فقط)
```

## 🌐 رفع الموقع على الإنترنت

### Railway (مجاني - الأسهل)
1. سجّل على https://railway.app
2. New Project → Deploy from GitHub
3. ارفع الملفات على GitHub أولاً
4. في الإعدادات: أضف متغير `JWT_SECRET`

### Render (مجاني)
1. https://render.com → New Web Service
2. Start Command: `node server.js`
3. أضف Environment Variables

### VPS (الأقوى)
```bash
# بعد الشراء
npm install -g pm2
pm2 start server.js --name arabic-chat
pm2 save && pm2 startup

# HTTPS مجاني عبر Nginx + Let's Encrypt
```
